Processed with japan-map-assets: municipal boundaries dissolved to prefectures and simplified; SVGs projected; video SVGs reposition southern islands into insets.

The source page identifies GSI Numerical Map (Basic Geospatial Information), GSI tiles, and MIC local government codes as original materials and records GSI reproduction approval R 7JHf 351. Some boundaries are provisional in the source. This tool preserves supplied boundaries and does not resolve disputed or undetermined boundaries. It does not constitute an official boundary determination.

Check the dataset-specific conditions before using a different source release. An input's provenance is supplied by the user, never inferred from its geometry. `manifest.json` records source date, input SHA-256, acquisition metadata when available, settings and output SHA-256. Pass `--source-date` and `--acquired-date` for manually obtained data. Keep this notice and provenance with redistributed assets.
